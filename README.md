# Fake News Headline Generator

A Python project that generates random fake news headlines using predefined templates and datasets.

## Features

- Random headline generation
- Multiple categories (celebrities, companies, politics, science)
- Simple and beginner-friendly Python code

## Run

```bash
python app.py
```

## Educational Purpose

This project is intended for learning Python, randomization, and text template generation. The generated headlines are fictional and should not be treated as real news.
